# 柔道技術紀錄｜場邊操作原型

給比賽時坐在場邊的夥伴與賽後檢討教練使用。系統分成「即時場邊」及「匯入賽事・AI 分析」兩種模式。

## 開啟

直接開啟 `index.html`，或在此資料夾執行：

```bash
python3 -m http.server 4174
```

再前往 `http://localhost:4174`。

## 原型功能

- 白方／藍方選擇，Ippon、Waza-ari、Yuko、Shido 與 Hansoku-make 快速標記
- 立技、寢技、轉換、攻防與比賽狀態分類
- 比賽倒數、Golden Score、暫停、時間校正
- 事件時間軸、一鍵復原、刪除單筆、文字與瀏覽器語音備註
- localStorage 本機自動保存，CSV／JSON 匯出
- 平板橫向、手機與桌面響應式介面

## 即時影像模式

- 使用電腦內建／外接 UVC 攝影機，或直接在手機瀏覽器使用後鏡頭
- LIVE 狀態燈、攝影機來源切換與裝置端錄影下載
- 0–5000 ms 手動延遲修正與閃光反應校正
- 校正後，事件時間會自動回推到影像實際發生時間

手機架最穩定的方式，是直接用手機開啟已部署的 HTTPS 網站並錄影。若要讓手機影像遠端傳到另一台電腦，需要額外的 WebRTC 訊號與連線服務，目前版本尚未宣稱具備。

## 匯入賽事與報告

- 匯入 MP4、MOV 或瀏覽器可播放的完整影片
- 以本機畫面差異掃描高動作候選時間點，不會上傳影片
- 教練確認選手方、事件類型、建議概念與自由評語
- 影片畫面上可拖曳關節點，標示左右肘、左右膝角度
- 報告包含事件照片、時間點、角度、建議、教練評語與確認狀態
- 透過列印功能輸出 PDF 報告

## 邊界

這是純前端場邊技術分析原型，不取代官方計分台或裁判判決。規則預設參考 IJF 2025 起的 Yuko 制，但賽事主辦單位可能採不同年齡組或地方規程；使用前應先核對該場競賽規則。

「AI 掃描」目前是可解釋的本機畫面變化偵測，用於縮小教練檢視範圍，並非已經過柔道專項資料訓練的技術分類模型。人體角度需由教練拖曳節點校正，才可納入報告。瀏覽器語音辨識與影片格式支援依裝置而定。
