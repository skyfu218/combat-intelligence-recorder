# 競技運動情蒐記錄系統

**Combat Intelligence Recorder（CIR）** 是給場邊分析夥伴與教練使用的本機優先 Web App。支援柔道、角力、跆拳道、空手道、拳擊、西洋劍，可在「即時場邊」與「匯入賽事・AI 分析」兩種模式間切換。

## 開啟

```bash
python3 -m http.server 4174
```

前往 `http://localhost:4174`。攝影機與麥克風在正式網站需使用 HTTPS。

## 六項運動記錄

- 柔道：Ippon、Waza-ari、Yuko、Shido，以及立技、寢技、轉換與握法。
- 角力：1／2／4 分、壓制勝、站立摔投、地板控制、被動與警告。
- 跆拳道：軀幹拳、軀幹踢、頭部踢、Gam-jeom、踢法與攻防。
- 空手道：Yuko、Waza-ari、Ippon、警告、拳法、踢法與 Senshu。
- 拳擊：10–9／10–8 回合判讀、擊倒、讀秒、拳法、攻防與判罰。
- 西洋劍：有效刺中、雙燈、無效燈、判罰牌、攻防與劍種判定。

切換運動會建立一場新的對戰，計時、快速得分鍵、技術分類、統計表及教練建議同步切換。

## 即時場邊

- 可使用內建／外接攝影機，或直接在手機瀏覽器使用後鏡頭。
- LIVE 狀態、來源切換、裝置端錄影下載及 0–5000 ms 延遲校正。
- 錄影期間的事件會綁定影片秒數；停止後點選時間軸事件，影片會回到事件前 2 秒播放。
- 事件依我方／對手統計，呈現各得分、技術、攻防及判罰次數。
- 紀錄存在瀏覽器 localStorage，另可下載 CSV／JSON。

若要把手機攝影機的即時畫面傳到另一臺電腦，仍需 WebRTC 訊號服務；目前版本不宣稱具備跨裝置串流。

## 匯入賽事與報告

- 匯入裝置可播放的完整影片，以本機畫面差異找出高動作候選時間。
- 可暫停影片並直接使用與即時場邊相同的運動技術標籤；每筆標記會保存影片秒數與當下畫面。
- 左側固定我方選手、右側固定對方選手，技術次數分欄累計，適合快速整理對手其他場次影片。
- 教練可確認事件類型、選手方、建議概念及自由評語。
- 可在畫面拖曳人體關節點，將左右肘／膝角度與事件照片存入報告。
- 可輸出含照片、時間點、事件、角度、建議與教練評語的多頁 PDF。
- LINE 分享優先使用裝置原生分享面板，可附 PDF 時會直接提供檔案；不支援檔案分享時，改分享網站與文字摘要。實際是否出現 LINE 由裝置已安裝的 App 與瀏覽器能力決定。

## 規則來源與使用邊界

介面欄位參考各總會目前規則文件：IJF、UWW、World Taekwondo、WKF、World Boxing 與 FIE。正式賽事可能因年齡、量級、劍種、賽制或主辦單位而不同，使用前仍須核對該場規程。

本系統是教練情蒐工具，不取代裁判、官方計分或正式成績。所稱 AI 分析目前是本機畫面變化偵測，用於縮小人工檢視範圍，不是經六項運動專項資料驗證的自動技術辨識模型；事件、人體點位、角度及建議皆須由教練複核。
